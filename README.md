## 🌰 About The Project

Squirrel Banking is a lightweight banking management web application developed as an Agile/Scrum practice project.

The application allows users to:

- 🔐 Register & Login
- 💳 View account information
- 📜 Check transaction history
- ➕ Add transactions
- ❌ Delete transactions

Built with:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express.js
- Project Management: Jira
- UI/UX Design: Figma
- Version Control: Git & GitHub
